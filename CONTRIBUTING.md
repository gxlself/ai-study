# 贡献指南 / Contributing

感谢你帮助改进芽芽成长 Sprout。请先阅读 [`README.md`](README.md)、[`docs/README.md`](docs/README.md)、[`CONTENT-LICENSE.md`](CONTENT-LICENSE.md) 和相关包的安全说明。

## 中文

### 环境

- Node.js `>=22.12`
- pnpm `11.1.0`
- 本地执行 pnpm 前设置 `export pnpm_config_verify_deps_before_run=false`

```sh
corepack enable
export pnpm_config_verify_deps_before_run=false
pnpm install
```

### 常用命令

```sh
pnpm typecheck
pnpm test
pnpm content:typecheck
pnpm content:test
pnpm qa:license
pnpm build
```

不要运行或提交 macOS `say` 生成的录音。`pnpm content:audio` 只用于个人非商业本地使用，生成文件在被忽略的 `audio/tts/`，本地清单在 `audio/manifest.local.json`。公开 bundle、ZIP、APK 和演示站不含预录音频。

### 内容安全

- 内容面向婴幼儿和照护者，避免恐吓、羞辱、危险模仿和不适龄材料。
- 不使用快速闪卡，不把课程正确率包装为发育诊断或学习效果承诺。
- 课程应鼓励家长回应、真实物品和线下活动，不设计自动连播、广告、排行或成瘾奖励。
- 图片、音频、视频、旋律和字体必须有可公开再分发的许可；`custom` 不是许可。
- 不提交 macOS 系统语音录音或任何未获授权的真人录音。
- 不加入统计、广告、追踪或未经说明的外部请求。

### 提交

提交信息沿用仓库现有 Conventional Commits 风格，例如 `feat(player): ...`、`fix(content): ...`、`docs: ...`、`test: ...`。

每个提交应包含 DCO 签名：

```text
Signed-off-by: Your Name <you@example.com>
```

提交代码即表示：代码贡献按 MIT 授权；内容贡献按 [`CONTENT-LICENSE.md`](CONTENT-LICENSE.md) 授权；你有权提供这些贡献，并同意作者可以把贡献纳入未来的商业授权或商业版本。需要商业许可或范围确认时，请在 issue 标注 `licensing` 或联系 `gxlself@gmail.com`。

PR 请说明测试命令、内容许可来源、无录音确认和必要截图。安全问题不要公开创建 issue，请按 [`SECURITY.md`](SECURITY.md) 提交。

## English

Thank you for helping Sprout. Please read [`README.en.md`](README.en.md), [`docs/README.md`](docs/README.md), [`CONTENT-LICENSE.md`](CONTENT-LICENSE.md), and the security notes for the package you change.

### Environment

- Node.js `>=22.12`
- pnpm `11.1.0`
- Set `pnpm_config_verify_deps_before_run=false` before local pnpm commands.

```sh
corepack enable
export pnpm_config_verify_deps_before_run=false
pnpm install
```

### Common checks

```sh
pnpm typecheck
pnpm test
pnpm content:typecheck
pnpm content:test
pnpm qa:license
pnpm build
```

Do not run or commit recordings generated by macOS `say`. `pnpm content:audio` is for personal, non-commercial local use only; generated files stay under ignored `audio/tts/` and `audio/manifest.local.json`. Public bundles, ZIPs, APKs, and the demo contain no pre-recorded audio.

### Child-safety and content rules

- Write for young children and caregivers; avoid fear, shame, dangerous imitation, and age-inappropriate material.
- Do not use rapid flash cards or present lesson accuracy as a developmental diagnosis or guaranteed learning outcome.
- Encourage caregiver response, real objects, and offline play. Do not add autoplay, ads, rankings, or addictive rewards.
- Images, audio, video, melodies, and fonts need a license that permits public redistribution. `custom` is not a license.
- Never submit macOS system-voice recordings or unlicensed human recordings.
- Do not add analytics, advertising, tracking, or unexplained external requests.

### Commits and contribution authorization

Use the repository's Conventional Commits style, such as `feat(player): ...`, `fix(content): ...`, `docs: ...`, and `test: ...`.

Every commit should include a DCO sign-off:

```text
Signed-off-by: Your Name <you@example.com>
```

By submitting a contribution, you state that you have the right to submit it, license code contributions under MIT, and license content contributions under [`CONTENT-LICENSE.md`](CONTENT-LICENSE.md). You also agree that the author may include the contribution in a future commercial license or commercial version. For licensing questions, label a GitHub issue `licensing` or email `gxlself@gmail.com`.

PRs should include the tests run, content-license sources, confirmation that no recordings are included, and screenshots when useful. Report security issues privately using [`SECURITY.md`](SECURITY.md).
