# s5 小小思考者：24–29 月龄家长指南

这一阶段，不是把宝宝变成会答题的小学生。一起分两件衣物，给玩偶摆一把勺，听他说“我还想玩”，都可以是学习。看、指、递物、做动作和说话，都是参与。任何熟悉宝宝的照护者都能陪，不需要昂贵教具或流利英语。

本文中的 `[n]` 对应 `docs/research/evidence-review.md` 第 10 节参考文献，不另造 `R` 编号。里程碑原文取自 `content/milestones/milestones.json` 的 `cdc-2022` 数据。

## 本阶段宝宝在发展什么

- **把短句接起来。** 24 月龄清单包括“能把至少两个词连在一起说”。宝宝说“猫里面”，你可以接“对，小猫在箱子里面”，再停下来听。回合对话与后续语言能力有关；对话式阅读为孩子提供主动说和被回应的机会，不等于多播几段音频就有效。[44][48][49]
- **观察相同与不同。** 成人可以先示范按一个特点分组，再让宝宝试。颜色名、类别词和独立分类都在逐步发展；不能把选错篮子当作发育异常。[7][69][71]
- **听数量，动手对应。** 数到五是本主题的探索范围，不是两岁达标线。跟着念数词、指一个说一个、知道最后那个数表示总数，是不同能力。成人示范眼前实物的点数和总数即可；这些研究多为相关性研究，不能承诺本课会提高智力或提前掌握算术。[63][64][65][69]
- **听懂位置与用途。** “盒子里”“桌子下”要连着参照物说，最好用玩偶操作。位置词和实际经验相连；图片只是引子。[67][71]
- **关注别人，练习轮流。** 宝宝可能注意到别人难过，仍需要大人帮助等待和处理冲突。先说“你也想玩”，再陪着短短轮流。不要求独立忍住哭、不强迫借出心爱玩具，不拿“懂事”评价感受。[7][83][90][91]
- **主动唱、读、动。** 看着照护者、模仿一次、在停顿时发声，都比把音乐一直开着更符合本项目的互动目标。相关音乐研究不能当作这三首歌的具体疗效证明。[87][88]

## 屏幕使用方式

### 先决定要不要给宝宝看

中国 2024 年《婴幼儿早期发展服务指南（试行）》提出 0–3 岁不接触视屏类产品；2023 年近视防控文件和 2025 年三部门通知也给出这一年龄尽量不用或禁用的口径。**完全不让宝宝看本阶段屏幕内容，是可行的选择，不会错过必须完成的学习任务。** 大人可先读本指南和课程的线下延伸，再关屏陪玩。[8][10][11]

本项目路线在 s5 设置 `audience: "child"`、`coView: "required"`、`childScreen: "default"`，是产品约定，**不是医学机构要求两岁开始看屏幕**。如家庭选择共看，要知晓它比上述中国文件更宽松。[1][3][6][8][11]

### 选择共看时的边界

- 本阶段每节标注 **4–6 分钟**。路线单次上限 **10 分钟**，每天最多 **2 节、合计 20 分钟**；这是产品上限，不是需要用满的剂量，也不要求每天开课。
- 电视、平板、手机、视频通话等所有屏幕都纳入家庭预算。较宽的 WHO、中国 2022 照护指南、AAP 2016 分龄建议为两岁后全天不超过 60 分钟、越少越好；这不覆盖或抵消中国较新的“不用屏”建议。[1][3][6][8][11]
- 先看宝宝是否舒服、清醒、愿意参与。家长先读导语，坐在身边，宝宝指图或说话时回应。不要一边陪看一边刷手机，不留背景电视。[25][27][32][33][40]
- 用餐、睡前一小时和卧室不用屏，不拿本课喂饭、哄睡或作为哭闹时的唯一安抚方式。默认可用窗口为 08:00–18:30，但具体还要避开自家用餐和睡前时段。[3][6]
- 在明亮舒适的环境里坐稳共看，不手持平板贴脸，不边走边盯屏。没有适合共看的空间，就直接用线下活动。中小学生的距离或休息公式不是婴幼儿的安全保证，不把它换算成“坐到某米就安全”。[9][10][11]
- 宝宝转头、烦躁、揉眼、困倦或想离开时，就结束。不要为了课程进度、倒计时或完整听完双语而继续。
- 开始前先约好一个线下活动：“看完去给玩偶摆勺子。”结束就关屏，不继续加课。看过的故事可在线下再讲，儿歌可真人再唱。[101][102]

### 几处容易误讲的地方

- **颜色：** 只看当前图片的主色。蓝色例子使用蓝碗、蓝手套，碗再出现一次用于同规则重复。现有蓝莓图偏紫，不作为蓝色答案；不把“蓝莓”这个名字当成颜色证据。
- **“不一样”：** 四张图能有多种不同，课程明确按种类或交通活动地点找。宝宝若按颜色指出另一张，先听他的理由，再说明本轮规则。找不同不用于给人或家庭贴标签。
- **动物的家：** “天上飞”指活动，不是永久的住所。小鸟、蝴蝶会落下休息；小鱼、鲸在水里游。鲸不是鱼。鸭、企鹅、青蛙等可能造成当前规则歧义的动物不入题。
- **熊猫：** 吃竹子、会爬树、睡觉和休息是动物行为，不意味着它只吃竹子、按人类时间作息或宝宝应模仿爬树。吃竹子的页面使用竹子词条图；树只用于环境和爬树，不把树或草当竹子。
- **情绪：** 选择题只匹配角色亲口说的感受，不规定某个事件让所有人产生唯一情绪。表情图不是诊断或读心工具。
- **礼貌：** 成人不因宝宝没说“请”而扣住基本帮助，不强迫说“对不起”、原谅、拥抱或分享。示范道歉要连着实际修复。
- **天气：** 有太阳也可能冷，晴雨不是完全互斥的两类；雨后不一定有彩虹。“雪花／snowflake”与“下雪／snowing”不是同一个词。风图是示意符号，不是风的真实形状。

## 一日生活中的学习

以下与 Stage 的八条 `dailyRhythm` 对应。一次只选一个自然机会，不把全天排成课程。

1. **起床看天气。** 站在关好且有防护的窗边，跟宝宝的目光说“今天有云”。等指、看或一个词。看云和地面，不直视太阳，不上窗台。
2. **穿衣给选择。** 大人先按实际冷热选两件都合适的衣物，让宝宝挑一件。不要只凭晴天或下雨图标决定穿多少。
3. **收衣物分一分。** 这次只按红、蓝分；另一次再按袜子、上衣分。不把颜色、大小、用途同时加成三条规则。
4. **准备餐具数一数。** 点一到三把儿童勺，点一个说一个，数完说“一共三把”。不要用葡萄、豆子、纽扣或瓶盖练数；餐具不含在嘴里走跑。用餐时关屏。
5. **地板游戏说位置。** 把玩偶放在开口盒子里或旁边，说清参照物。宝宝决定下一次位置，成人接话。只搬玩偶，不让宝宝进箱、合盖或爬上家具。
6. **户外短轮流。** 适合外出时，在成人看护下滚球或用适龄滑梯。宝宝暂时不想等，可以陪着先玩别的。户外时间和身体活动分散在日常生活里，屏幕不要挤占它们。[6]
7. **白天共读。** 只读几页，跟宝宝的兴趣停住。宝宝说“熊猫吃”，你接“熊猫吃竹子”。问一句后留足时间，不连续考叫什么、几只、什么颜色。
8. **睡前用真人和纸书收尾。** 提前关好设备，睡前一小时不用屏。选纸书或真人哼唱熟悉歌，不用本课亮屏哄睡，也不让设备整夜放音乐。[3][6][92]

## 中文与英语怎么带

中文是本家庭交流的主干。英语是可选的共同体验，不是两岁需要达到的语言成绩。双语本身不会导致语言迟缓，但每种语言的输入量和说话者熟练度影响输入质量。对发育有担忧时，不用“双语所以晚说”来代替儿保咨询。[50][51][53]

- **先选舒适模式。** `zh` 适合先用中文对话；`zh-en` 可先中文、再一句熟悉英语；不因为课程有双语就必须连听两遍。`en-zh` 或 `en` 仅在成人能够自然解释和回应时选择。歌唱每次选一种语言即可。
- **一句接一句。** 宝宝说“猫”，成人接“小猫在里面”，再等回应。不要求纠正发音或重复成人完整句。
- **英语放在动作里。** 举手时说“Hands up.”，轮流时说“Your turn.”，实际递书时说“Thank you.”。语境清楚比反复点读同一个词更重要。
- **不用英语替代熟练中文。** 不熟悉的句子可以不用。不要为了输入量全天放英语音频，也不承诺会说几首歌就会双语。
- **接受手势和混用。** 看、指、点头、递物，或中英混用，都可以回应。对话式阅读以宝宝表达和成人接话为中心，不以完整输出为考核。[48][50][82]

## 数学启蒙怎么带

### 点一个，说一个，再说总数

开始只放一个或两个大物品。家长手指点一个，说一个数；点完接“一共两只”。宝宝还会漏数、重复数或只念数词时，不急着纠正整串，可以一起示范一次。三只鸭、四个苹果、五颗星是课程给大人一起探索的集合，不是宝宝独立表现要求。[63][64][65][69]

不以认数字代替认识数量。本阶段的点数课关闭数字字形显示。“一眼看出几个”停留五秒、关闭数字选择，画面会重现；允许再点数，没有作答倒计时，也不要求记住短暂图形。

### 分类只定一个规则

先摆两个样本，讲“今天按颜色分”。成人示范一件，再等宝宝尝试。看到孩子另有分类依据时先理解，再重申当次规则。理解颜色名、认出同类和独立执行规则并不等同。[69][71][83]

### 让位置词有东西可指

用玩偶和开口盒子说“里面、外面、旁边”，再逐渐加“上、下、后”。“下”要说明在谁下面。不用家具攀爬、绳圈或封闭箱来验证理解。[67][71]

### 倒数不变成减法题

鸭子歌里，一只回家就移一张大卡。大人可说剩下的数量，但不问“五减一等于几”。两张卡也能玩。最后五只都在家，一起点数确认，不制造走失、找不到妈妈或危险水边情节。

## 本阶段里程碑观察

**这是日常观察参考，不是诊断工具。** CDC 2022 清单描述多数儿童在对应月龄能做到的事，不是学习成果考试，也不代表所有宝宝同时做到。不能根据本课选择题、英语跟读或数不到五判断发育。观察放在熟悉、舒适的日常场景中；有担心时与儿科或儿保医生讨论。

## 什么时候咨询医生

CDC 建议，如果未达到一个或多个对应月龄里程碑、失去曾经掌握的能力，或家长有其他担心，就向医生说明并询问发育筛查，不靠重复看课等待改善。清单不能替代标准化筛查。[CDC：`milestones.json` 来源及其 2 岁清单]

- 发现宝宝失去已掌握的语言、手势、动作或互动能力时，及时联系儿科或儿保医生。
- 在清醒、安静且熟悉的情境里，经常对声音没有反应，或你担心听力、视力、交流或动作时，告诉医生具体表现；不要用更大音量、突然噪声或反复叫名自行测试。
- 对对应月龄条目持续有担心时，记录几个真实例子，带上语言环境、身体健康和观察记录，与医生讨论是否需要听力、视力或发育方面的评估。

本指南不诊断语言障碍、自闭症或其他疾病，不提供课程“疗效”、用屏治疗或训练替代就医的建议。

|---|---|---|

每行有效音符数与中文字数或英文音节数一致，长音用拍数表示，不多唱一个字补音。中文原创词注明署名，两首传统旋律保留“旋律：传统（公有领域）；中文词：芽芽成长原创”。鸭子歌按路线明确允许的原创旋律例外如实署名，不将原创冒称传统。

## 编写与交接说明

- 本阶段保留 18 个课程 JSON 和本指南；本次只替换课程中的新增词条引用，不修改完整路线、词库、schema、脚本或其他阶段。
- 数量严格保留：点数三只鸭、四个苹果、五颗星；感数一、二、三、二；鸭子歌后的点数为五只鸭。点数均为 `guided`，数量题不使用群体图或不可数名词。
- 分类、指认、情绪、穿戴题无超出 props 契约的字段。情绪与穿戴情境通过独立 `story` 步骤给出，`choose` 的三轮顺序与情境对应。
- 所有词卡手动翻页，所有儿歌只唱一遍，所有绘本没有循环动画。课程文案中的“时间”是建议和边界，不是考核限时。

### 集成前独立校验

在仓库根执行下面的只读命令，检查 s5 的结构、活动 props、词库和资源引用、标点以及 Stage 课程归属；不依赖尚未合并的完整路线，也不生成文件。

```sh
npx tsx --eval '
import fs from "node:fs";
import { Stage, validateLesson } from "@sprout/schema";
import { resourceIssues, punctuationIssues, routeIssues } from "./scripts/lib/validate-pack.ts";
(async () => {
  const root = "content/packs/sprout-core";
  const read = file => JSON.parse(fs.readFileSync(root + "/" + file, "utf8"));
  const knownConcepts = new Set(read("lexicon.json").concepts.map(c => c.id));
  const stage = Stage.parse(read("routes/_stages/s5.json"));
  const files = fs.readdirSync(root + "/lessons/s5").filter(f => f.endsWith(".json"));
  const entries = [];
  const issues = [];
  for (const file of files) {
    const result = validateLesson(read("lessons/s5/" + file), { knownConcepts });
    issues.push(...result.issues);
    if (!result.lesson) continue;
    const lesson = result.lesson;
    entries.push({ file, lesson, issues: result.issues });
    issues.push(...await resourceIssues(root, lesson, file, knownConcepts));
    issues.push(...punctuationIssues(lesson, file));
  }
  const route = { schemaVersion: 1, id: "sprout.core.route", title: { zh: "阶段校验" }, stages: [stage] };
  issues.push(...routeIssues([{ file: "routes/_stages/s5.json", route }], entries));
  console.log({ lessons: entries.length, themes: stage.themes.length,
    errors: issues.filter(i => i.level === "error").length,
    warnings: issues.filter(i => i.level === "warning").length });
  for (const issue of issues) console.log(issue);
  if (files.length !== 18 || issues.length) process.exitCode = 1;
})().catch(error => { console.error(error); process.exitCode = 1; });
'
```

合并后再运行 `npx tsx scripts/validate-content.ts --pack content/packs/sprout-core`。完整路线缺失、其他阶段写入中的状态，以及待生成音频应单独由集成负责人处理，不能当作本阶段已通过整包发布验收。
