# s1 感知世界：6～8个月家长指南

这不是宝宝的屏幕课。十二节都是给家长读的陪玩指引。先了解一小段，再放下屏幕，看看眼前的宝宝。

这里的“家长”包括爸爸、妈妈、祖辈及其他熟悉的照护者。照片、称呼和晚安流程，都按家中实际情况替换。一天只选一个小玩法也很好，不需要把课程做完才算陪伴。

本文的 `[n]` 对应 `docs/research/evidence-review.md` 第十节参考文献。里程碑文字来自 `content/milestones/milestones.json` 的六个月条目。课程是互动参考，不是训练处方或医疗建议。

## 1. 本阶段宝宝在发展什么

**看脸、听声、来回交流。** 宝宝可能看向熟悉的人，发一个声音，等你接住。你可以轻声模仿，再留几秒空白。看你、动动手、转开脸，都有值得回应的信息。六个月起的家长辅导研究支持儿向语言与回合对话；不需要用不停说话来填满所有空白。[47][82]

儿向语言不是随意编错词。用真实、简单的词，语速慢一点，语调温柔而明显。一句“你好呀，宝宝”，然后等一等，就可以开始。

**看移动、够东西、尝试动作。** 本阶段提供实体卡、真实照片和安全的地板游戏。不把宝宝摆成还不能保持的坐姿或站姿，不拉着练爬。六个月清单中，抓想要的玩具、俯卧撑起上身、用手支撑坐姿都是日常观察点，不是本课要同时完成的任务。

**清醒时分次陪趴。** WHO对未会移动的婴儿建议每天清醒时累计至少三十分钟俯卧，分散在一天中，不是连续趴三十分钟。每次几分钟或更短，累了就停。已经能自己移动的宝宝，也需要安全空间自主翻滚、够取、移动；不能用单一俯卧目标代替自由活动。[1][2][89]

**遮一点，再一起发现。** 躲猫猫和半藏玩具可以先从共同观看开始。不会主动揭布、不会找全藏住的玩具，不算这节课失败。CDC九个月清单才列躲猫猫时微笑或大笑，十二个月清单才列寻找看到被藏起的东西。不要把后面的条目提前当成六到八个月的要求。

**音乐是人与人的小互动。** 家长唱一句、停一下、回应宝宝，比无人互动的背景播放更符合本项目的设计依据。主动亲子音乐研究并不证明某一首歌、某一节课就能提升智力或教会英语。[87]

高对比卡是可选陪看材料，**不是提高视力、智力或识字能力的“训练卡”**。不用快速闪卡；没有打印条件，用家长的脸、真实照片和适龄玩具也可以。[6][8][21]

## 2. 屏幕怎么用

| 对象 | 本阶段安排 |
| --- | --- |
| 宝宝 | 不看本课程屏幕内容；`childScreen` 为 `none` |
| 家长 | 每课阅读、预习约二到三分钟；阶段单次提示三分钟、每日提示十分钟 |
| 每日课数 | 排课建议两节，不是必须完成两节 |
| 陪玩 | 每课 `guide.playMin` 为五分钟，只是提醒窗口；可随时提前结束，包含停顿与休息 |
| 可视化材料 | 宝宝看实体卡、真人、真实照片和防碎婴儿镜，不看电子卡片 |
| 儿歌 | 白天由家长学旋律；关屏后亲自唱，不循环播放给宝宝听 |

三分钟、十分钟是家长预习的产品提示，**不是允许宝宝看屏幕的额度**。`coView: required` 表示照护者必须参与，不表示本阶段可以让宝宝一起看电视。

家长阅读时由另一位照护者照看宝宝，或安排在宝宝安全安置、不需要即时照护的片刻。正在喂养、换尿布、陪趴或抱着走动时，不一边看手机一边操作。先记住一个动作，屏幕放下后再开始。[6]

吃饭、哭闹安抚、亲子游戏和睡前不用屏幕。睡前一小时也不预习歌曲；摇篮曲白天学会，晚上只用人声轻唱。若宝宝偶然看向设备，收起设备即可，不需要责备或制造焦虑。[3][6]

宝宝睡眠少、正在烦躁、不舒服或家庭当天很忙时，可以不打开课程。普通照护中的温柔回应，本身就是重要的相处机会。

### 实体材料怎么准备

- 一次拿一张，不同时铺满所有卡。追视先停住，再缓慢左右移动；约二十到三十厘米只是本活动的摆放建议，不是视力测量标准。
- 动物、家人、五官卡使用大尺寸，默认不显示中英文字。只让家长指图说名字，不教宝宝读字。
- 家人课优先使用已有真实照片或真人。可由家长按需在后台上传后打印；上传不是完成课程的条件，宝宝不看照片的手机预览。
- 卡片由大人拿，边角磨圆。湿软、掉屑、破损即收起，勿含咬。不用订书钉、小夹子、小磁铁或绳子固定。
- 宝宝喜欢把物品放进嘴里探索。可抓握的材料选完整、适龄、可清洁的大玩具；直径小于三点五厘米的物件有窒息风险，尺寸更大也不代表安全。还要排除小零件、钮扣电池、磁铁、气球及包装袋。
- 布只用于遮家长自己的脸或玩具，不盖宝宝口鼻、不绕头颈。结束后收走，不留在睡眠区。镜子选防碎、圆角、无破损的婴儿镜，并拿稳或可靠固定。

## 3. 主题与课程一览

主题周数为三、三、三、四周，共十三周。它们是可反复轮换的陪玩建议，不是十三周的达标训练。宝宝持续喜欢某个玩法，可以多重复；不喜欢的先略过。

| 课程 | 目标 | 线下延伸 |
| --- | --- | --- |
| 黑白卡片追视 | 陪看缓慢移动的实体卡，尊重转开目光 | 看看熟悉的脸 |
| 看看脸，说说话 | 家长接住声音、目光或笑容，再等待 | 穿衣时应一声 |
| 趴一趴，看一看 | 清醒陪趴，自主抬头或够取，分次休息 | 够够大玩具 |

打印材料：黑白的靶心、条纹、棋盘、圆形、圆点；黑白笑脸、心形、圆点；黑白红的圆形、星形、心形、螺旋。图案是陪看选择，不要求认出名称。图形示意可在家长端看，给宝宝看的始终是实体材料。

### 三首儿歌的安排与来源

| 歌曲 | 本课编写 | 旋律与核对来源 |
| --- | --- | --- |
| 小星星 | 中文原创两段、传统英文一段；C大调，84拍 | 法国传统旋律《Ah! vous dirai-je, maman》，公有领域。英文为Jane Taylor《The Star》（1806）首段，加传统重复句；文本可核对多伦多大学图书馆Representative Poetry Online的《The Star》 |
| 王老先生有块地 | 中文原创奶牛段与传统英文奶牛段；C大调，84拍；其他动物卡在线下换声聊 | 传统《Old MacDonald Had a Farm》，公有领域。旋律、弱起与短音节节奏参考University of Redlands Kodály Center的American Folk Song Collection，条目895，移调后录入；不复制该站排版、录音或编曲 |
| 摇篮曲 | 中英均为项目原创词；C大调，60拍 | Johannes Brahms《Wiegenlied》，Op.49 No.4（1868），公有领域。参考Mutopia编号1037的声乐主旋律，原降E大调移至C大调，省略两处装饰倚音及钢琴前奏，不使用现代录音 |

每行发声音符数与中文字数或英文音节数一致，休止符不算字。摇篮曲采用一字或一音节对应一个主旋律音，未照搬原德文的连音配词。中文词不是英文逐字译文，而是相同玩法中的适龄新词；摇篮曲的中英原创词均围绕陪伴和晚安。

录入旋律供家长学唱，不是给宝宝播放的背景音。唱不熟也可以只哼一小句。睡前困了就收尾，绝不为听完一首歌延迟入睡或忽略哭声。

## 4. 一日生活中的学习

以下与阶段的八条 `dailyRhythm` 对应。不需要按表从早做到晚，也不建议把宝宝全天时间变成课程。

| 生活片刻 | 家长可以做什么 | 可以说什么 |
| --- | --- | --- |
| 起床 | 面对面问好，叫一次名字，等待目光或声音，不反复催 | “你好呀，宝宝。” |
| 换尿布、穿衣 | 先告知，再轻柔操作；只说一个五官或眼前动作 | “穿衣啦。”“这是鼻子。” |
| 喂养 | 回应宝宝的进食与停下信号，不用屏幕吸引进食 | “还想吃吗？”“我们停一停。” |
| 清醒地板游戏 | 分次陪趴，玩具放在可触及处，等待自主够取；不拉拽练爬 | “我在这里。”“小手够一够。” |
| 短段陪看 | 看一张实体卡或真实照片，慢慢命名，留停顿 | “这是宝宝。”“慢慢移过去。” |
| 散步或窗边 | 跟着宝宝的目光，说身边真实事物；天气不适合就不勉强外出 | “你在看树呀。” |
| 家人相处 | 一位家人先发声或接宝宝声音，再把回合留给宝宝 | “我听见啦。” |
| 睡前 | 按需要换尿布、穿睡衣，轻哼熟悉的短歌，回应需要后说晚安 | “我在这里。”“晚安，宝宝。” |

宝宝闭唇表示不想再吃，是六个月清单的一项观察。尊重这样的信号，比用游戏催着多吃更符合回应性照护。课程不规定进食量或辅食方案，有相关疑问请咨询儿保医生。[6][8]

## 5. 中文与英语怎么带

**中文是日常交流主干。** 家长用最熟悉、最自然的语言，跟宝宝看同一个东西，等同一个回应。家中原本使用方言或其他语言时，不必为这套课程硬改照护者自然的说话方式。

**英语是可选的短段相处。** 会说就加一句“Hello, baby.”，或轻唱熟悉的英文歌。中文一句后不一定立刻翻译；不要因为追着双语流程而错过宝宝的声音。只用中文也完全可以。

如果家长需要选择语言模式，可从 `zh` 开始，熟悉英语的家庭再选择 `zh-en`；已有稳定英语交流的家庭可按自身习惯选择。模式选择不改变s1不给宝宝看屏幕的规则。

双语本身不会导致语言迟缓，但每种语言的输入量、交流质量与说话者熟练度都重要。“一人一语”不是必须规则。不要用不熟练的英语取代丰富的中文回应，也不承诺几首儿歌就能形成英语能力。[50][51][52][53]

录播视频或一直接着放音频，不能代替真人互动。常被引用的外语语音研究对象是九个月婴儿，不能推成“本课六到八个月听歌就会学会英语”的结论。[16]

## 6. 数学启蒙怎么带

这个阶段**不要求会数数、认数字、认形状、看点数答题**。婴儿研究中的注视差异，不等于宝宝能说出数量或做算术。[60][61][62][69]

可以保留生活里的体验：卡片慢慢移到一边，家长说“这边”；玩具露出一点，家长说“还在这里”；儿歌唱同一句，停一下，再唱。这些是空间、出现与重复的体验，不把它们当成数学能力测验。

儿歌重复节奏可作为规律体验，但不能据此承诺数学提升。项目中的数字谈话研究主要观察十四个月以上儿童，学前规律研究也不能直接外推到本阶段。[64][65][68][69]

愿意重复一个小玩法，就是足够好的起点。不增设算术闪卡，不用分数、奖励、连续打卡或与别的宝宝比较。

## 8. 什么时候咨询医生

以下不是诊断结论，也不是让家长在家制造声音、反复遮脸来测试宝宝。

- 发现宝宝**失去已经掌握的能力**，及时与儿科或儿保医生沟通，不等后续课程。
- 日常多次观察仍对声音缺少反应，或家长对听力有担心，及时咨询医生。CDC听力资料提示，六个月以后不转向声源是需要关注的信号；不能用课程中一次没转头自行诊断。
- 对六个月清单中的表现有担心，或对宝宝的交流、动作、视听反应有持续担忧，带着具体观察去咨询医生，不必等到“落后很多”才问。[6][8]

一次没有笑、没有发声、没有掀布，不能得出诊断结论；同样，也不要用“每个宝宝都不同”来忽略家长的持续担忧。沟通时可以说清“什么时候、什么情境、看到什么”，不用课程完成率替代发育评估。

```ts
import assert from 'node:assert/strict';
import { readFileSync, readdirSync, statSync } from 'node:fs';
import { Stage, Lexicon, Route, validateLesson, BUILTIN_ACTIVITY_PROPS } from '@sprout/schema';
import { punctuationIssues, resourceIssues, printableIssues, routeIssues } from './scripts/lib/validate-pack.ts';

const root = 'content/packs/sprout-core';
const read = (file) => JSON.parse(readFileSync(file, 'utf8'));
const lexicon = Lexicon.parse(read(`${root}/lexicon.json`));
const known = new Set(lexicon.concepts.map((item) => item.id));
const assets = new Map(lexicon.concepts.map((concept) => [concept.id, { concept, root }]));
const stage = Stage.parse(read(`${root}/routes/_stages/s1.json`));
const doc = readFileSync('docs/curriculum/s1.md', 'utf8');
const research = readFileSync('docs/research/evidence-review.md', 'utf8');
const referenceNumbers = new Set([...research.matchAll(/^(\d+)\. /gm)].map((match) => `[${match[1]}]`));
const expected = [
  ['contrast-shapes', 'contrast-faces', 'tummy-time'],
  ['family-faces', 'my-face', 'twinkle'],
  ['peekaboo-hands', 'hide-toy', 'mirror'],
  ['farm-sounds', 'old-macdonald', 'lullaby'],
];
const domains = [
  [['cognition'], ['social', 'language'], ['motor']],
  [['social', 'language'], ['language', 'science'], ['music', 'english']],
  [['social', 'cognition'], ['cognition'], ['social']],
  [['language', 'science'], ['music', 'english'], ['music', 'life']],
];
const cards = {
  'family-faces': ['mom', 'dad', 'baby', 'grandma-paternal', 'grandpa-paternal', 'caregiver'],
  'my-face': ['eye', 'nose', 'mouth', 'ear'],
  'hide-toy': ['dog', 'cat', 'duck'],
  'farm-sounds': ['dog', 'cat', 'cow', 'duck'],
  'old-macdonald': ['cow', 'pig', 'duck', 'sheep'],
};
const contrast = {
  'contrast-shapes': ['bw', ['bullseye', 'stripes', 'checker', 'circle', 'dots']],
  'contrast-faces': ['bw', ['face', 'heart', 'dots']],
  'tummy-time': ['bwr', ['circle', 'star', 'heart', 'spiral']],
};
const upgradedIllustrations = {
  'family-faces': { 1: 'caregiver' },
  'my-face': { 0: 'mirror' },
  mirror: { 0: 'mirror', 1: 'mirror', 4: 'caregiver' },
  twinkle: { 1: 'caregiver' },
};
const multiple = { twinkle: 2, little: 2, wonder: 2, above: 2, diamond: 2, macdonald: 3, everywhere: 3 };
const monosyllables = new Set('star how i what you are up the world so high like a in sky old had farm e o and on his he cow with moo here there good night sleep tight my love hear song soft slow rest now am hands feet can as well right dear warm hugs sweet dreams'.split(' '));
const short = (text) => assert.ok((text.match(/\p{Script=Han}/gu) ?? []).length <= 12, text);
const entries = [];
let songLines = 0;
let songs = 0;
let guides = 0;

assert.deepEqual(stage.ageRange, [6, 8]);
assert.equal(stage.id, 's1');
assert.ok(stage.focus.length >= 4 && stage.focus.length <= 6);
assert.ok(stage.focus.every((item) => item.zh && item.en));
assert.ok(stage.title.en && stage.subtitle.en);
assert.ok(stage.dailyRhythm.length >= 5 && stage.dailyRhythm.length <= 8);
assert.deepEqual(stage.screen, { sessionMaxMin: 3, dailyMaxMin: 10, lessonsPerDay: 2, coView: 'required', childScreen: 'none' });
assert.deepEqual(stage.milestonesAt, [6]);
assert.deepEqual(stage.themes.map((theme) => theme.weeks), [3, 3, 3, 4]);
assert.equal(stage.themes.length, 4);
assert.equal(readdirSync(`${root}/lessons/s1`).filter((file) => file.endsWith('.json')).length, 12);

for (const [themeIndex, slugs] of expected.entries()) {
  const theme = stage.themes[themeIndex];
  assert.equal(theme.id, `s1-t${themeIndex + 1}`);
  assert.deepEqual(theme.lessons, slugs.map((slug) => `core.s1.${slug}`));
  assert.ok(theme.title.en && theme.description.en);
  assert.ok(theme.offlineFocus.length >= 2 && theme.offlineFocus.length <= 4);
  for (const [lessonIndex, slug] of slugs.entries()) {
    const file = `lessons/s1/${slug}.json`;
    const raw = read(`${root}/${file}`);
    const result = validateLesson(raw, { knownConcepts: known });
    assert.deepEqual(result.issues, [], file);
    assert.equal(raw.id, `core.s1.${slug}`);
    assert.equal(raw.themeId, theme.id);
    assert.equal(raw.audience, 'parent');
    assert.equal(raw.coView, 'required');
    assert.deepEqual(raw.ageRange, [6, 8]);
    assert.deepEqual(raw.domains, domains[themeIndex][lessonIndex]);
    assert.ok(raw.durationMin >= 2 && raw.durationMin <= 3);
    assert.ok(raw.title.en && raw.summary.en);
    short(raw.title.zh);
    short(raw.summary.zh);
    assert.equal(raw.steps[0].type, 'guide');
    assert.ok(raw.objectives.length >= 1 && raw.objectives.length <= 3);
    assert.ok(raw.objectives.every((item) => item.zh && item.en));
    raw.objectives.forEach((item) => short(item.zh));
    assert.ok(raw.parentGuide.tips.length >= 2 && raw.parentGuide.tips.length <= 4);
    assert.ok(raw.parentGuide.phrases.length >= 3 && raw.parentGuide.phrases.length <= 6);
    assert.ok(raw.parentGuide.why && raw.parentGuide.refs.length);
    raw.parentGuide.refs.forEach((reference) => assert.ok(referenceNumbers.has(reference), reference));
    raw.parentGuide.phrases.forEach((phrase) => { assert.ok(phrase.en); short(phrase.zh); });
    assert.deepEqual(punctuationIssues(raw, file), []);
    assert.deepEqual(await resourceIssues(root, raw, file, known), []);
    assert.deepEqual(await printableIssues(root, result.lesson, file, assets), []);
    assert.ok(raw.offline.length >= 1 && raw.offline.length <= 2);
    for (const offline of raw.offline) {
      assert.ok(offline.steps.length >= 2 && offline.steps.length <= 6);
      assert.ok(offline.safety && offline.question && offline.levels.easier && offline.levels.harder);
      short(offline.question);
    }
    const references = [raw.cover.concept];
    if (slug === 'mirror') assert.equal(raw.cover.concept, 'mirror');
    for (const [index, concept] of Object.entries(upgradedIllustrations[slug] ?? {})) {
      assert.equal(raw.steps[0].props.steps[Number(index)].concept, concept, `${raw.id}：升级插图`);
    }
    if (slug === 'family-faces') {
      assert.deepEqual(raw.steps[0].props.steps[1].say, {
        zh: '这是陪你的人。', en: 'This is your caregiver.',
      });
      assert.deepEqual(raw.steps[0].props.steps[2].say, {
        zh: '陪你的人在这里。', en: 'Your caregiver is here.',
      });
    }
    for (const step of raw.steps) {
      assert.ok(['guide', 'song'].includes(step.type));
      const props = BUILTIN_ACTIVITY_PROPS[step.type].parse(step.props);
      if (step.type === 'guide') {
        guides++;
        assert.ok(props.steps.length >= 3 && props.steps.length <= 6);
        assert.ok(props.playMin >= 5 && props.playMin <= 15);
        assert.ok(props.observe.length >= 2 && props.observe.length <= 3 && props.safety);
        props.steps.forEach((item) => {
          assert.ok(item.say?.zh && item.say?.en);
          short(item.say.zh);
          if (item.concept) references.push(item.concept);
        });
      } else {
        songs++;
        assert.equal(props.repeat, 1);
        assert.ok(props.credit.includes('公有领域') && props.credit.includes('原创'));
        if (slug === 'lullaby') assert.equal(props.bpm, 60);
        props.scene.sprites.forEach((item) => references.push(item.concept));
        for (const line of props.lines) {
          const tokens = line.notes.trim().split(/\s+/);
          tokens.forEach((note) => assert.ok(Number(note.split('/')[1]) > 0));
          const count = tokens.filter((note) => !note.startsWith('R/')).length;
          const syllables = line.lang === 'zh'
            ? (line.text.match(/\p{Script=Han}/gu) ?? []).length
            : (line.text.match(/[A-Za-z]+/g) ?? []).reduce((sum, word) => {
                const key = word.toLowerCase();
                assert.ok(multiple[key] || monosyllables.has(key), `请人工确认音节：${word}`);
                return sum + (multiple[key] || 1);
              }, 0);
          assert.equal(count, syllables, `${raw.id}：${line.text}`);
          if (line.lang === 'zh') short(line.text);
          songLines++;
        }
      }
    }
    if (cards[slug]) {
      assert.equal(raw.printables.length, 1);
      const printable = raw.printables[0];
      assert.equal(printable.kind, 'cards');
      assert.deepEqual(printable.items, cards[slug]);
      assert.equal(printable.size, 'large');
      assert.equal(printable.showText, false);
      assert.equal(printable.showEnglish, false);
      references.push(...printable.items);
    } else if (contrast[slug]) {
      assert.equal(raw.printables.length, 1);
      assert.equal(raw.printables[0].kind, 'contrast');
      assert.equal(raw.printables[0].palette, contrast[slug][0]);
      assert.deepEqual(raw.printables[0].patterns, contrast[slug][1]);
    } else assert.equal(raw.printables?.length ?? 0, 0);
    for (const reference of references) {
      assert.ok(typeof reference === 'string' && known.has(reference), reference);
      assert.ok(statSync(`${root}/${assets.get(reference).concept.image}`).size > 0, reference);
    }
    assert.ok(doc.includes(raw.title.zh), raw.id);
    entries.push({ file, lesson: result.lesson, issues: [] });
    console.log(`PASS ${raw.id}`);
  }
}
const route = Route.parse({ schemaVersion: 1, id: 'sprout.core.route', title: { zh: 's1专项自检' }, stages: [stage] });
assert.deepEqual(routeIssues([{ file: '仅内存中的s1路线', route }], entries), []);
const milestones = read('content/milestones/milestones.json');
const sixMonths = milestones.items.filter((item) => item.ageMonths === 6);
assert.equal(sixMonths.length, 12);
sixMonths.forEach((item) => assert.ok(doc.includes(item.zh), item.id));
assert.ok(doc.includes(milestones.disclaimer.zh));
assert.deepEqual([guides, songs, songLines], [12, 3, 50]);
console.log(JSON.stringify({ lessons: entries.length, themes: stage.themes.length, guides, songs, songLines, milestoneItems: sixMonths.length, errors: 0, warnings: 0 }));
```
