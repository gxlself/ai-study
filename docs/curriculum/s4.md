# s4 语言爆发：18–23 月龄家长指南

适用阶段：`s4`。六个主题，18 节课，其中 12 节家长指引、6 节可选亲子共看。家长指引阅读约 2–3 分钟；线下陪玩约 5–10 分钟，随宝宝兴趣提前结束也可以。每个主题可反复玩，不必每天换新课。

本指南的数字参考文献编号对应 `docs/research/evidence-review.md` 第 10 节；里程碑中文原文来自 `content/milestones/milestones.json`。口腔、水边看护和洗手的补充官方资料单列在文末，不冒用现有研究编号。

## 本阶段宝宝在发展什么

宝宝可能更常指给你看、拿东西来求助，或用几个词表达需要。也可能先理解很多，开口仍不多。“语言爆发”是阶段名称，不承诺每个宝宝都突然说很多话。18 月龄与接近 24 月龄的观察项目不同，不把“两词组合”提前变成 18 月龄的作业。

最值得投入的是你来我往。宝宝指一只球，你回应“球，大球”，然后停一下。看、指、递给你、发声都可以是一回合。有关回合对话的研究支持重视互动，但不能据此承诺某节课增加多少词。[44][47][82]

颜色、形状、大小和数量都是生活中的经验，不是背诵任务。宝宝可以只摸摸两个碗、看你点数三把勺子。会背“一二三”不等于理解三个，也不要求他现在独立配形、排序或认颜色。[63][64][65][67][69][71]

涂鸦、套放和搭建让宝宝自己试。情绪来时，他仍需要成人帮助调节。说“你生气了，我在这里”是陪伴的开始，不是让哭闹立刻消失的口令。幼儿家长情绪辅导研究提供了参考，但不支持把认脸卡或一次呼吸当作有效治疗。[90][91]

任何稳定照护者都能陪玩：爸爸、妈妈、祖辈或其他照护者均可。故事中的“妈妈”可按家里熟悉的称呼讲述，不规定谁负责刷牙、做饭或安抚。

## 屏幕使用方式

### 默认不给宝宝看

本阶段首先推荐家长先读、放下设备，再与宝宝玩真实物品。打印卡替代电子卡；故事也可以由家长拿卡讲。共看课默认关闭，完全不启用不会漏掉必须学习的内容。

这是面向中国家庭的保守选择。证据综述所引中国 2024 年早期发展指南与 2025 年三部门文件建议 0–3 岁不接触或禁用视屏类产品；2022 年照护指南也不建议两岁以内使用电子屏幕。[6][8][11]

`route-plan.md` 允许 s4 家长主动开启少量共看，采用 AAP 2016 年对 18–24 月龄“若引入，选择高质量内容并共用”的条件性口径。[3] 这比上述中国建议宽松，不代表屏幕有必要，更不代表观看能替代真人互动。研究综述第 9.1 节“6–24 月龄屏幕只给家长看”的原则与路线表的可选入口存在表述差异；本阶段数据按任务指定的路线表实现，同时保留默认关闭和线下替代。

### 家庭已选择共看时

- 每节全程由家长陪同，宝宝可以看、指，由家长代按。不提供独自观看。
- 单次上限 8 分钟。本阶段实际共看课建议 4–6 分钟，没看完也可结束。
- 每天最多一节共看，App 内共看累计上限 10 分钟。“每日两节课”是课程安排，不是允许看两节屏幕课。
- 全天所有设备与电视的观看都要计入家庭预算。项目的全部屏幕累计 60 分钟硬上限不是本月龄的推荐量；两岁以内仍以不用屏幕为默认。[1][3][6]
- 默认可用时段为 08:00–18:30。用餐、睡前一小时、卧室和正在哭闹需要安抚时不用。宝宝早睡时应更早结束，而不是等到 18:30。[3][6]
- 卡片手动慢翻，故事读一页停一下。不快速闪卡、不背景播放，不追求全部做完。
- 看完就关屏，接上本课线下活动。不追加一节，也不重复观看到答对。[15][27]

家长指引只有在宝宝没有观看时，才不计入宝宝屏幕时间。家长看资料也应尽量避开正在照护和交流的时刻。水边绝不拿设备看步骤或倒计时。[40]

## 一日生活中的学习

与 Stage 的 `dailyRhythm` 对应。选一个顺手的机会就够，不必把一天变成八项任务。

1. **起床穿衣**：拿起一件单色衣物，先让宝宝看，再说“蓝色上衣”。如果他说“衣”，可回应“上衣，蓝色的”。颜色短句按眼前实物替换，不机械套用课里的红色示例。
2. **摆餐具和吃饭前**：点一把说“一”，点下一把说“二”，最后说“两把勺子”。需要时示范到三。吃饭时不测数、不喂饭追问、不看屏幕。
3. **玩积木**：地上放一个宽底大块，递下一块。说“放上面”“高一点”。宝宝只加一块也可以。推倒前清开手脚，倒了再试，不向人扔。
4. **安全散步**：看看圆钟或轮子图片，说“圆圆的边”。球是立体的，不能说成平面的圆形。只看太阳图片，不直视太阳；不靠近车轮或行驶车辆。
5. **整理东西**：两只同色袜子放一起，或比两个同形空碗。说“比这个大”“比旁边的小”，让比较对象清楚。小不等于差，大不等于更有价值。
6. **情绪来时**：放下设备，先查安全及饥饿、疲倦、疼痛等需要，再用短句陪伴。可以说“你生气了，我在”。拒绝拥抱时坐近；不强迫呼吸。能回应后再给两个可行选择，例如再搭或休息。伤人动作要温和挡住，情绪本身不用禁止。
7. **洗手和洗澡**：照护前预告，做时命名“手”“脚”。用品提前备齐；专一成人在水边始终手臂可及，不接电话、不离开。计时只是提示，不能让看护中断。
8. **每天刷牙两次**：乳牙萌出后由成人帮助清洁；三岁以下用米粒大小含氟牙膏。睡前那次不开屏。宝宝选牙刷或拿毛巾即可，不要求独自刷干净。五分钟活动时间包含准备和照护，不是连续刷五分钟。[93] 具体口腔来源见补充资料 A。

## 中文与英语怎么带

中文是本家庭高质量交流的主干。`zh` 模式完全可以；家长能自然说几句英语时，可选 `zh-en`。`en-zh` 或 `en` 适用于有持续、熟练英语输入的家庭，不作为更高级的模式。

先回应宝宝正在关注的东西，再自然补一个词。例如宝宝指袜子，你说“红袜子”，愿意时再说“Red sock”。不把每句中文都翻译一遍，也不要求宝宝交英文答案。中文、英语或手势都接受；孩子暂时混用语言，不因此贴上“混乱”或“迟缓”的标签。[50][51][53]

语言输入的量与质量很重要，但本课不承诺几分钟英语就能达到双语水平。家长英语不熟时，优先自然、丰富的中文来回交流；少量英文固定短语和亲子歌唱是可选补充，不用长时间音频或视频“磨耳朵”代替交流。[16][53][54]

短句示例：

| 情境 | 中文 | 英语 |
|---|---|---|
| 指袜子 | 红袜子，在这里。 | Red sock, right here. |
| 放积木 | 放上面，高一点。 | On top, a little higher. |
| 数完鞋 | 一、二，两只鞋子。 | One, two. Two shoes. |
| 求助 | 我在，想让我帮忙吗？ | I'm here. Would you like help? |
| 比杯子 | 这只比旁边的小。 | This one is smaller. |

### 本阶段儿歌

只有 `core.s4.wash-song` 含 `song`：洗手、刷牙、梳头三个主题段，中英文歌词均为芽芽成长原创。旋律取路线表允许的传统公有领域 **Mulberry Bush**，不使用现代商业儿歌原词、现成录音或伴奏。

采用常见 6/8 拍谱形，移到 C 大调，速度 90 BPM，合成钢琴，完整播放一次。每段四行，有声音符数依次为 **9、7、9、6**；每行均为六个四分音符时值，即两个 6/8 小节。中文逐字配音符；英文 `little` 按两音节，其余本课用词按一音节核对，逐行同为 9、7、9、6。

歌曲只提供共享节奏与动作。先在干燥处空手模仿，真实照护时关屏。单个歌段不是二十秒洗手计时，也不是完整刷牙计时。[87]

## 数学启蒙怎么带

**数量**：用眼前一到三个安全实物。“一、二、三，三个苹果”要有每个物体对应一次指点，最后再说总数。唱数用“二”，量词短句用“两把勺子”“两条小鱼”。不给小豆子、硬糖或坚果做教具，也不把跟说数词当作会按数取物。[63][64][65][69]

**多少**：共看只比较一个与三个同样的苹果。不把图片大小或物种差异混进数量问题。在线下可以请宝宝看两组，家长分别点数；不会选多的一组也不需要重做。

**形状**：圆卡是平面图形；盘边、钟面和轮廓可与它比较。球是立体物体，说“看起来圆圆的”。只说“这块饼干圆”，不说所有饼干都圆。形状卡先配两张完全相同的，再按兴趣添加干扰项。

**大小和空间**：比较两个同类物品，明显差异更容易观察。套杯先两个，不硬压卡住的杯子。搭塔时说“上面”“高一点”“倒了变低”。成人可以示范三四块，宝宝不必达到示范量。[67][71]

**动作里的数词**：木头人只停一两秒，坐着拍手也行。不淘汰、不比较，不要求憋气或强制身体不动。“变大变小”是姿势比喻，宝宝的身体没有瞬间改变真实大小。

每课线下的开放问题是邀请，不是考试。宝宝可以看、指、拿、选；如果没有回应，家长自然示范或改玩别的。更难的玩法只在宝宝有兴趣时尝试。

## 什么时候咨询医生

这些是通用的咨询建议，不由本课程判断病因或下诊断：

- 失去已经掌握的语言、互动或动作能力，应及时联系儿科／儿保医生。
- 对声音持续没有反应，或家长担心听力、日常理解和交流时，请向医生说明，不自行用大音量测试。
- 到对应月龄仍未观察到某些清单项目，或者你有其他担心，可以现在就咨询。不要等做完课程，不靠增加屏幕或反复训练来替代发育评估。

记录发生时间、原来会做什么、现在怎样，在儿保随访时带上。医生决定是否需要进一步筛查或转诊。一次没回答、不想配合或游戏时走神，不能单独作为异常结论。参考 CDC 的“如有担心，及早行动”建议及仓库里程碑声明；听力担忧可在儿保随访中提出。

## 照护安全与补充资料

**小物件**：课程提示直径小于 3.5 厘米的小物件有窒息风险，这不是“大于此值就一定安全”的判定。适龄玩具仍需检查材质、可拆小件、纽扣、电池、磁铁、锐边和破损。粗蜡笔无毒也不能吃，断笔与碎屑立即收走。卡片用大张厚纸，成人剪裁；不入口、不盖口鼻。

**口腔**：乳牙萌出后每天两次，三岁以下米粒大小含氟牙膏，成人挤并帮刷。不会吐时不强迫漱口；不让宝宝自行挤牙膏或含牙刷走跑。明显疼痛、出血或持续刷牙困难请咨询牙医。特殊口腔情况按个体医嘱处理，不由课程给治疗方案。

**水边**：浅水也可能溺水。专一成人始终手臂可及，片刻不离开。用品提前备齐，先调温试温，确认温热不烫再入水，入水后不再加热水。要离开先抱出并带走宝宝，用完倒空水。防滑，电器远离。浴椅或漂浮玩具不能替代看护。

**洗手**：湿手、涂皂搓至少 20 秒、冲净、擦干。搓到手心、手背和指间，由成人帮助。歌只提醒动作，不作清洁计时。

补充官方来源（核对日期：2026-10-03）：

- **A：AAPD，Policy on Use of Fluoride**。支持每天两次含氟牙膏及三岁以下米粒大小用量。`https://www.aapd.org/globalassets/media/policies_guidelines/p_fluorideuse.pdf`
- **A 补充：AAPD，Frequently Asked Questions**。支持乳牙萌出后由家长使用适龄软毛牙刷、少量含氟牙膏帮刷。`https://www.aapd.org/resources/parent/faq/`
- **B：AAP／HealthyChildren，Bathroom Safety**。支持浅水风险、全程监督、用品提前备齐和防烫。水加热器上限不是洗澡水的建议温度，本课不混用二者。`https://www.healthychildren.org/English/safety-prevention/at-home/Pages/Bathroom-Safety.aspx`
- **C：CDC，About Handwashing**。支持涂皂后手部搓洗至少 20 秒、冲净、擦干。`https://www.cdc.gov/clean-hands/about/index.html`
- **D：CDC，Milestones by 18 Months**。支持未达到对应观察项目、失去技能或其他担忧时及时联系医生。项目中文以仓库整理数据为准。`https://www.cdc.gov/act-early/milestones/18-months.html`

以下定向命令只读 s4；临时 Route 只在内存中用于检查 Stage 与课程归属，不落盘、不合并其他阶段。还检查本阶段引用的词库图片存在。命令依次执行，不并行校验：

```sh
pnpm exec tsx -e '
import assert from "node:assert/strict";
import {readFileSync,readdirSync} from "node:fs";
import path from "node:path";
import {Lexicon,Stage,Route,validateLesson} from "@sprout/schema";
import {resourceIssues,punctuationIssues,routeIssues} from "./scripts/lib/validate-pack.ts";
const pack=path.resolve("content/packs/sprout-core");
const read=(file:string)=>JSON.parse(readFileSync(file,"utf8"));
const lex=Lexicon.parse(read(`${pack}/lexicon.json`));
const knownConcepts=new Set(lex.concepts.map(c=>c.id));
const used=new Set<string>();
function collect(v:any):void {
  if(typeof v==="string"&&knownConcepts.has(v)) used.add(v);
  else if(Array.isArray(v)) v.forEach(collect);
  else if(v&&typeof v==="object") Object.values(v).forEach(collect);
}
(async()=>{
  const stage=Stage.parse(read(`${pack}/routes/_stages/s4.json`));
  const files=readdirSync(`${pack}/lessons/s4`).filter(f=>f.endsWith(".json")).sort();
  assert.equal(files.length,18);
  const entries:any[]=[];
  const issues:any[]=[];
  for(const file of files){
    const result=validateLesson(read(`${pack}/lessons/s4/${file}`),{knownConcepts});
    assert.ok(result.lesson,file);
    const lesson=result.lesson!;
    entries.push({file,lesson,issues:result.issues});
    issues.push(...result.issues,...punctuationIssues(lesson,file));
    issues.push(...await resourceIssues(pack,lesson,file,knownConcepts));
    collect(lesson);
  }
  for(const id of used){
    const c=lex.concepts.find(c=>c.id===id)!;
    issues.push(...await resourceIssues(pack,{image:c.image},`concept:${id}`,knownConcepts));
  }
  const route=Route.parse({schemaVersion:1,id:"sprout.core.route",title:{zh:"芽芽成长"},stages:[stage]});
  issues.push(...routeIssues([{file:"s4 in-memory Route",route}],entries));
  assert.equal(entries.filter(e=>e.lesson.audience==="parent").length,12);
  assert.equal(entries.filter(e=>e.lesson.audience==="child").length,6);
  assert.equal(stage.themes.length,6);
  for(const theme of stage.themes){
    assert.equal(theme.lessons.length,3);
    assert.equal(entries.filter(e=>theme.lessons.includes(e.lesson.id)&&e.lesson.audience==="child").length,1);
  }
  console.log({stage:stage.id,lessons:entries.length,assets:used.size,issues});
  assert.deepEqual(issues,[]);
})().catch(e=>{console.error(e);process.exitCode=1;});
'
```
