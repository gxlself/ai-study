# 芽芽成长：家长工作台

## 打开与首次设置

让手机、电脑、电视或 iPad 连接同一个家庭网络。浏览器打开服务器的 `/admin/`，例如 `http://家庭服务器地址:4310/admin/`。

第一次打开时，依次填写家庭名、至少 6 位管理员密码，以及第一个孩子的名字、生日和语言模式。以后使用管理员密码登录。管理员密码和课程预览链接不要分享给孩子或家庭以外的人；预览链接包含临时使用的管理员凭据。

截图位置：`apps/admin/test-artifacts/mobile-setup-complete.png`；桌面概览见 `desktop-dashboard.png`。

## 每天从这里开始

顶部可以切换孩子。今日概览显示孩子的月龄、当前阶段与主题、今日课程和屏幕时间。课程的原因标签分别代表主题、复习、置顶或领域均衡。过去七天的图表反映实际记录到的屏幕使用时间，不代表能力评分。

课程下的线下活动可以在关掉屏幕后继续。芽芽成长是亲子共学工具，不会把持续播放作为目标。

截图位置：`desktop-dashboard.png`、`mobile-dashboard.png`。

## 孩子档案与计划

在“孩子档案”中添加或编辑名字、昵称、生日、动物头像与语言模式：

| 模式 | 内容顺序 |
| --- | --- |
| 中文 | 只使用中文 |
| 中文 + 英文 | 中文在前，英文在后 |
| 英文 + 中文 | 英文在前，中文在后 |
| 英文 | 只使用英文 |

拼音供家长参考，可单独开关。屏幕模式有“自动”“仅家长指引”“开启亲子共看”：6–17 月龄不能开启亲子共看，使用打印实体卡和家中实物；18–23 月龄默认仅家长指引，家长主动开启共看后每次最多 8 分钟且须全程陪同；24–36 月龄共看单次硬上限 20 分钟，仍须家长陪同。

这些设置依据 `docs/research/evidence-review.md` 第 9 节整理的中国卫健委、教育部、WHO 和 AAP 口径。家长指引课只给家长看，读完放下设备去陪玩，不计入孩子屏幕时间。自动模式跟随路线的 `childScreen` 策略。

孩子首次处于共看模式时，档案页显示可关闭的知情提示，按孩子在本机记已读。s4 每日最多一节共看课；选择仅家长模式且本阶段家长课不足时，今日计划以“线下版”补足，孩子不观看活动步骤。

屏幕时间留空时跟随成长阶段的默认值；超过阶段建议会显示黄色提示。每日所有屏幕合计不超过 60 分钟、越少越好。默认可用时段为 08:00–18:30，可设置多个时段，开启开始前的护眼距离提醒；用餐时及睡前一小时不要使用屏幕。

计划默认按月龄自动安排，也可以选择当前主题、置顶课程、跳过课程、加强某些领域。置顶与跳过不要设置为同一节课。删除孩子会同时删除其学习记录，操作前会要求确认。

截图位置：`desktop-children.png`、`mobile-children.png`。

## 成长路线与课程

“成长路线”按阶段展示适用月龄、发展重点、屏幕策略、一日作息和主题。当前孩子所在阶段与主题会被标注。点课程可以查看目标、家长导语、短语、步骤和线下活动。

“课程库”支持月龄、领域、内容包、主题和关键字筛选，以及卡片或表格显示。详情中的“预览”打开播放端，不自动改变孩子的学习记录。内置课程不能直接修改；先“复制为我的课程”，再编辑。

课程类型徽标区分“家长指引课”和“亲子共看课”。有“可打印”徽标的课程可直接打开实体卡打印页；成长路线的每个主题还提供“打印本主题卡片”，合并该主题全部课程的打印材料。

截图位置：`desktop-route.png`、`desktop-lessons.png`、`mobile-lessons.png`。

## 制作自己的课程

从课程库新建课程，填写中英文标题、月龄、领域、建议时长、陪同要求和目标，再补齐家长导语与至少一项线下活动。

选择“家长指引课”时，仅能新增 `guide` 活动指引或 `song` 儿歌步骤。已有不适合的步骤不会被悄悄删除，必须由家长修改后才能保存。亲子共看课起始月龄至少 18 个月并须全程陪同。

添加步骤时可以选择已启用的活动类型，目前有 17 种内置活动。每步根据活动参数定义生成表单；词条选择器带图片，图片字段可上传素材。电脑上可拖动步骤排序，也可使用上下移动按钮。JSON 模式适合熟悉数据格式的家长，格式不正确时不能保存。

线下活动可以填写开放式问题，以及“更简单”“更有挑战”两种玩法。编辑器中的“可打印实体材料”可添加词卡或高对比卡：填写标题、选词条、选尺寸和中英文开关；高对比卡可选择图案和黑白或黑白红配色。

右侧或底部是实时预览。保存时先做本地结构检查，再提交服务器，由服务器校验后保存；问题会列出具体字段位置。活动预览依赖播放端启动，播放端不可用时不会影响已保存课程。

后台切到隐藏状态或超过 90 秒没有可识别的互动时会卸载预览并显示暂停，恢复需要家长点击“继续预览”。这不产生孩子记录；播放端实际课程的计时和暂停由播放端独立负责。

截图位置：`desktop-editor.png`、`mobile-editor.png`。

## 打印实体卡片

课程打印路由为 `/admin/print/lesson/<课程 id>`，主题打印路由为 `/admin/print/theme/<主题 id>`。打印视图不会带侧边栏、顶部孩子选择器或其它后台框架。

浏览器选择 A4 纵向和实际大小打印，后台页已提供细裁切线。大卡每页 2 张、中卡每页 4 张、小卡每页 8 张；高对比图每页一张。图片加载完成后打印按钮才可用，缺图时请先修复词库，不要打印缺失材料。

建议使用硬卡纸或过塑，裁好后剪圆边角。宝宝啃咬或拿卡片玩时需要成人全程看护，不要留下小碎片。6–17 月龄的可视化材料是这些实体卡，不是给宝宝观看手机或电视。

截图位置：`desktop-print-lesson.png`、`desktop-print-theme.png`、`desktop-print-contrast.png`、`mobile-print-lesson.png`。打印验证文件保存在 `test-artifacts/`，不提交。

## 词库与语音

在“词库”按类别或关键字查找图片、中英文和拼音。自定义词条可以加入家人照片等熟悉事物。图片上传后才会写入课程素材目录；请只上传有权使用的照片，保护家人隐私。

朗读按钮优先使用可用语音能力；服务端无语音时可使用浏览器语音。浏览器与设备不同，声音也可能不同。不支持语音的设备会提示，不会假装播放成功。

截图位置：`desktop-lexicon.png`、`mobile-lexicon.png`。

## 成长观察与学习记录

“里程碑”按 6、9、12、15、18、24、30、36 月龄分组。每条可以记为“已做到”“正在萌芽”或“还没有”，并记录日期与备注。可以回看不同月龄的观察完成度。这只是家庭观察记录，不是诊断工具，请以页面的完整说明为准。

“学习记录”列出课程、日期、时长、完成情况和播放设备，可筛选日期范围，并查看近 30 天统计。

截图位置：`desktop-milestones.png`、`desktop-sessions.png`。

## 内容包与活动插件

内容包可以导入 zip、启停、导出、重新扫描和查看校验问题。内置包、自定义包与已安装包会区分来源。素材署名及许可在内容包详情中显示。

同 ID 同版本可以覆盖回导，也可以升级，不能降级；保留启停状态，导入版优先于同版本内置包，内置源码不会被覆盖。

内置活动与第三方插件分开展示。第三方插件可通过 zip 或远程 `plugin.json` 地址安装。安装前请核实来源，安装后检查网络、麦克风、摄像头、存储等权限声明；不信任的插件不要启用。权限声明是作者声明，不等于安全审计结果。删除或停用插件可能影响使用它的课程。

截图位置：`desktop-packs.png`、`desktop-plugins.png`。

## 电视与 iPad

先在电视浏览器或 iPad Safari 打开“播放设备”页面显示的播放端地址。iPad 也可以在 Safari 中添加到主屏幕。播放端申请连接后会显示 6 位配对码；在后台“添加设备”输入该码，填写设备名并绑定孩子。配对码有效期为 10 分钟，过期后请重新申请。

可以改设备名字、改绑孩子或吊销设备。吊销后原设备凭据失效，需要重新配对。开发服务器的 `localhost` 只表示当前机器，电视上应使用家庭服务器的局域网地址。

截图位置：`desktop-devices.png`、`mobile-devices.png`。

## 家庭设置与备份

“家庭设置”可以更改家庭名、配置 TTS provider 与中英文声音、试听和修改密码。下载备份后妥善保管，其中含孩子资料、学习记录及家庭内容。恢复会覆盖现有资料，务必先备份当前数据，并核对要恢复的文件。

备份 API 的范围由服务器控制。设备 token 不包含在备份中；恢复后是否需要重新配对，以服务器的恢复提示为准。自定义照片、音频等二进制素材是否完整包含在备份中，请同时参照服务器说明，不要只依赖 JSON 备份保管原始照片。

截图位置：`desktop-settings.png`、`mobile-settings.png`。

## 开发与验收

仅 `apps/admin/**` 与本文由 T4-admin 维护；共享 schema、播放端、服务器和内容包由对应任务维护。

```sh
pnpm --filter @sprout/admin dev
pnpm --filter @sprout/admin typecheck
pnpm --filter @sprout/admin test
pnpm --filter @sprout/admin build
```

测试默认使用一个 worker。机器负载高或并行任务修改依赖时，可临时使用 `PNPM_CONFIG_VERIFY_DEPS_BEFORE_RUN=false pnpm --filter @sprout/admin <命令>` 复用已装依赖，避免 pnpm 自动重新安装；typecheck、test、build 与浏览器验证请串行执行。

开发地址：`http://localhost:5311/admin/`。`/api`、`/packs`、`/plugins` 默认代理到 `http://localhost:4310`。可用 `SPROUT_API_TARGET=http://localhost:4410` 指定备用后端；被占用时可用 `pnpm --filter @sprout/admin dev --port 5411`。

开发预览指向同一主机 `5310` 端口的 `/#/preview/<id>`，并附加 `server=<后台 origin>`，通过后台代理读取 API，也让播放端准确校验跨端口的消息来源；正式构建指向服务器根。课程草稿通过限定播放端 origin 的 `postMessage` 传递，不向任意网页广播。

### 无服务端的开发演示

打开 `http://localhost:5311/admin/?mock=1`，演示密码为 `sprout-demo`。首次设置验收使用 `?mock=1&setup=1`。mock 仅在 Vite 开发模式、显式指定参数时启用，不会进入正式构建。

演示记录保存在内存，整页刷新会重置。mock 的登录凭据单独存于 sessionStorage，不覆盖正式 `localStorage["sprout.adminToken"]`。每页都有“开发演示”标记。演示包导入导出、第三方插件安装与备份恢复不会实际执行，应在真实后端验收。

### 浏览器截图

```sh
# Playwright 已在本包依赖解析路径中时：
pnpm --filter @sprout/admin test:e2e

# 或复用本机已有 Playwright，避免改共享依赖：
PLAYWRIGHT_MODULE=/绝对路径/playwright/index.mjs pnpm --filter @sprout/admin test:e2e
```

脚本默认启动临时 `5411` 开发服务，结束后关闭它，覆盖桌面 1440×1000 与手机 390×844。可设置 `SPROUT_ADMIN_PORT`；连接已有服务时设置 `SPROUT_ADMIN_URL=http://localhost:5311/admin`，脚本不会关闭外部服务。

截图和 `smoke-results.json` 位于 `apps/admin/test-artifacts/`，该目录已加入包内 `.gitignore`。上述截图位置说明均指此目录。浏览器验收还需单独运行播放端，才能检查预览中的真实互动活动。

### 接口边界

API 契约没有单独的“只校验、不保存”课程接口。后台不臆造校验路由：先使用 `@sprout/schema` 检查，再调用约定的 POST/PUT，由服务器在落盘前校验并返回 issues。若后续增加独立预检接口，可在不改课程表单的前提下接入。
