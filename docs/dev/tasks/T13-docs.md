# T13 — 项目 README 与家长使用手册

## 所有权
`README.md`（仓库根，新建）、`docs/README.md`（文档索引，新建）、`docs/guide/**`（新建）。其它文件只读。

## 产出
1. `README.md`：芽芽成长是什么（亲子共学，不是电子保姆；循证要点 5 条，链接研究报告）、功能一览（播放端/后台/内容/插件）、架构图（Mermaid）、目录结构、快速开始（安装依赖、生成内容、构建、启动服务、浏览器打开后台与播放端）、电视/iPad 安装入口（链接 docs/deploy，T8 并行在写，链接即可）、扩展（内容包 / 插件 文档链接）、开发（测试、任务单、契约）、许可与素材署名（Fluent Emoji MIT 等）、免责声明（不是医疗建议，里程碑不是诊断工具）。命令必须与仓库实际 scripts 一致（读 package.json 核对）。
2. `docs/README.md`：所有文档的分组索引（研究、课程、开发、部署、指南），一句话说明每篇。
3. `docs/guide/parent-manual.md`《家长使用手册》（面向非技术家长，温和易懂）：第一次设置（服务器、后台、添加孩子、配对电视）→ 每天怎么用（6–17 月：看指引→放下屏幕→陪玩；打印卡片怎么做；18–23 月：可选共看；24–36 月：共看课怎么陪、线下版）→ 中英文怎么带 → 数学启蒙怎么在生活里做 → 里程碑观察怎么记 → 屏幕时间设置与原因 → 常见问题。内容依据 docs/research 与 docs/curriculum/*.md，不得夸大效果。
4. `docs/guide/content-roadmap.md`：96 节课程总览表（阶段/主题/课程/类型/领域），由脚本或手工从 `content/packs/sprout-core/lessons` 与 `_stages` 生成，保证与实际文件一致。
