# T17 — 电视 / iPad 界面打磨（家长侧页面"一屏放下"）

## 所有权
`apps/player/src/**`、`packages/activities/src/**`（仅界面与布局；不改活动行为契约）。其它只读。

## 问题（来自 Claude 审阅 qa-artifacts 截图）
1. `guide`（家长活动指引）在 1920×1080 下：焦点黄框包住整块内容并与顶部关闭/暂停按钮重叠；"给家长的陪玩指引"小标题被关闭按钮遮挡；右侧有一个含义不明的蓝色圆点（若是滚动指示/进度，请改为清晰的样式或去掉）；内容超出一屏需滚动。
2. 线下版课程页（offlineOnly）、课程结束页的线下活动卡：在电视上高度超过 1080，需要滚动。
## 要求
- 横屏 16:9（≥1280 宽）时，家长侧页面采用**两栏布局**：左栏"一起这样玩"步骤（含"可以这样说"中英短句），右栏"准备材料 / 观察要点 / 安全提醒 / 一起想一想 / 三档玩法"；主按钮（开始陪玩 N 分钟 / 完成线下活动）固定在底部安全区内，始终可见。目标：常见课程在 1920×1080 与 1280×720 下一屏放下；内容确实超长时，内容区可用方向键平滑滚动（上下键），并有"↓ 还有内容"的柔和提示，焦点框不得与顶部栏重叠。
- 4:3（iPad 1024×768）可单栏滚动，但主按钮固定可见。
- 顶部栏（关闭/暂停/步骤点）与内容区之间留出安全间距；焦点样式只框住真正可操作的元素（按钮、可滚动区域用较细的内描边或左侧指示条，不用整块大黄框）。
- 字号：家长正文在电视 3 米外可读（≥ 2.6vmin），中英短句英文略小、颜色较浅。
- 不得引入不兼容 Chrome 70 的 CSS（flex gap、aspect-ratio、inset、clamp 等，见 T9b 任务单）。
- 用 Playwright 对以下课程在 1920×1080、1280×720、1024×768 截图对比（修改前/后）：core.s1.contrast-shapes、core.s2.real-bubbles、core.s4.calm-down、core.s6.animal-pattern（线下版）、任一 child 课结束页；截图存 `apps/player/test-artifacts/polish/`。
## 验收
player / activities 的 typecheck、test、build 通过；截图中无重叠、无截断，主按钮可见。
