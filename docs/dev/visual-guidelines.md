# 视觉与交互规范（孩子侧界面）

设计令牌：`packages/plugin-sdk/src/tokens.css`（播放端与所有活动必须引用，不得另起一套颜色）。

## 画面
- 舞台 16:9 自适应（电视 1920×1080、iPad 横屏 4:3 时上下留白用背景色填充）；所有尺寸用 vmin/百分比；四周留 `--sp-safe` 安全边距。
- 背景柔和低饱和（奶油/天空/草地），主体物体高对比、居中、大（占舞台高度 40–60%）。避免大面积纯白（电视眩光）与纯黑。
- 一屏只讲一件事：主体 1 个（词卡）或 2–4 个可选项（找一找）。文字极少，图在前、字在后。
- 字体：中文 `--sp-font`，英文 `--sp-font-en`；孩子看的主词 `--sp-font-xl`；家长提示 `--sp-font-sm` 放在底部提示条。
- 插画：Fluent Emoji（MIT）彩色 SVG + 自绘简洁 SVG（形状/数字/颜色），风格统一、圆润、无恐怖/暴力/尖锐元素。

## 动效与声音
- 动画 ≥ 450ms、ease-in-out；循环动画缓慢（呼吸感 3–6s 一周期）；**禁止 >3Hz 闪烁、快速抖动、快速剪辑**；尊重 reduced-motion。
- 不自动连播：每步结束需要按键/点按才进入下一步（除 contrast/song 等本身设定的节奏）；整节课结束回到结束页，不自动开始下一节。
- 音效柔和、低音量（WebAudio 合成，主增益 ≤ 0.25）；错误反馈只用轻轻摇一摇 + 温和的 "再找找"，**没有刺耳音、红叉、扣分**。
- 鼓励语聚焦过程（"你找到了！""你看得真仔细"），不发虚拟星星/金币，不排名。

## 输入
- 遥控器 D-pad：方向键空间导航（带 `data-focusable` 的元素），OK=确认，返回=家长门（长按 2 秒或连按）。
- 触屏：点按为主；**不依赖拖拽**（2 岁前拖拽困难）；触控目标 ≥ `--sp-touch-min`。
- 焦点态：`--sp-focus-ring` 粗暖黄外发光 + 放大 1.06，必须在 3 米外清晰可见。
- 提示文案随输入方式变化："按 OK 键" ↔ "点一点"。

## 家长提示条
- 屏幕底部半透明条，`--sp-font-sm`，显示本步 parentTip / 对话式阅读提问 / 活动 setParentHint 内容；可在设置中关闭。
