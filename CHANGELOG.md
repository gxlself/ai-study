# Changelog

All notable changes to Sprout are documented here.

## [0.0.1] - 2026-10-05

### 中文

- 首个公开开源版本，包含家庭服务器、家长后台、电视/iPad/浏览器播放端、离线 `sprout.core`、内容包导入导出和活动插件契约。
- 提供 6 个成长阶段、家长指引、亲子共看、线下延伸活动、打印卡、屏幕策略、家长门和本地记录。
- 提供 `sprout.culture`、`sprout.english` 与 `sprout.hello` 内容包，以及内容校验、bundle、ZIP 和可再分发版权守卫。
- 增加 GitHub Pages 演示构建，部署到 `/ai-study/demo/`，数据只保存在浏览器本地。
- 公开仓库、APK、内容 ZIP 和演示构建不含任何预录音频；播放端在无音频时回退到 Web Speech API 或文字。
- 明确代码 MIT、原创内容 CC BY-NC 4.0 加商业授权、第三方素材按各自许可的结构。
- 内容包自身的版本是内容版本：`sprout.core`、`sprout.culture`、`sprout.english`、`sprout.hello` 继续保持 `1.0.0`，不与应用版本混用。

### English

- First public open-source release with the family server, parent admin, TV/iPad/browser player, offline `sprout.core`, content import/export, and the activity plugin contract.
- Includes six growth stages, parent guidance, co-viewing, offline extensions, printable cards, screen policies, parent gate, and local records.
- Includes `sprout.culture`, `sprout.english`, and `sprout.hello`, plus content validation, bundle, ZIP, and redistribution-license checks.
- Adds a GitHub Pages demo at `/ai-study/demo/` with browser-local data.
- The public repository, APK, content ZIPs, and demo contain no pre-recorded audio; the player falls back to Web Speech API or text.
- Documents the split between MIT code, CC BY-NC 4.0 original content with commercial licensing, and third-party notices.
- Content-pack versions remain content versions: `sprout.core`, `sprout.culture`, `sprout.english`, and `sprout.hello` stay at `1.0.0` and are separate from the application version.
