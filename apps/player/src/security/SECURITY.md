# T22 播放端安全约定

## 预览

使用 `#/preview/<id>?previewToken=<十分钟只读凭据>`，拒绝旧的 `token` 参数。
凭据消费后使用 `history.replaceState` 移除 URL 中的凭据，仅在当前实例内存中保存。
预览不读取设备连接、不访问设备或记录接口、不将临时状态写入 localStorage/sessionStorage。
服务端仍须校验 scope 与有效期；后台负责凭据签发和到期卸载预览。

草稿只接收父窗口且 origin 等于明确的后台 origin：
默认是配置的家庭服务器；本地开发 5310/5410 分别对应后台 5311/5411。
后台独立部署时设置构建变量 `VITE_SPROUT_ADMIN_ORIGIN`。不以 referrer 推导信任。

## 设备凭据与队列

`sprout.deviceToken` 为保持电视配对仍持久化在 localStorage，
同源脚本和可信 ESM 插件可以读取它，这不是安全存储，也不是插件隔离。
家庭服务器不得直接暴露公网；跨网络使用 HTTPS；丢失设备应在后台吊销。
当前 SDK 没有平台安全存储适配，本次没有改变这项契约。

远程历史使用 `sprout.remote:v2:<SHA-256([server,token])>`，
摘要不能作为 API 凭据，不在键或队列值里重复保存原始 token。
启动时枚举并迁移所有可识别旧身份，先写新身份队列、再移除可反解 token 的旧键，
保留未上传记录与 clientId，不使用当前设备凭据上传其它身份的记录。
主动切换连接或清除连接会删除旧身份的本机队列及所有旧格式凭据键；
离线档案和其它 v2 身份不受影响。未上传记录应在切换前完成同步。

## CSP 与插件

HTML 提供引导期 CSP（无 eval/object/base/form 能力），支持开发服务器和首次配对。
读取插件登记后、执行第三方模块之前，追加只允许自身及已登记 entryUrl 的脚本策略；
图片/音频仅允许自身、已配置服务器和 blob/data。
连接保留 HTTP(S)，以便首次配对、远程插件入口预检与独立 H5 的 CORS HEAD 检查；
这不提供插件网络能力隔离，也不能阻止同源可信插件主动外传数据。
已配置服务器支持局域网 HTTP 和公网 HTTPS，不用全网段脚本通配符。
生产运行期不允许内联脚本；引导和开发期只按代码 hash 放行当前 Vite React
刷新引导与同源 WebSocket。升级 Vite React 后需同步这些 hash 并跑开发浏览器验收。
由于浏览器的多条 CSP 只能收紧，新服务器或新增入口需要重开页面。

插件仅允许已启用登记入口，拒绝 data/blob/javascript、嵌入凭据及 resolver 替换。
入口预检不跟随重定向。实际模块仍为同源 ESM，不保证代码签名、内容固定或能力隔离；
预检与 import 之间的来源服务器内容变化也不提供完整 TOCTOU 防护。仅安装可信来源。
远程插件应为单文件 ESM，未登记的跨源依赖不会被 CSP 放行。

## 媒体

视频、poster、captions 和预加载只接受包内路径或已配置服务器同源地址，
拒绝协议相对地址、嵌入凭据、重复编码穿越、任意外站及媒体 data/blob 引用。
预加载不带凭据/referrer，不跟随重定向；最多 64 个资源、4 个串行工作流，
单资源读取上限 2 MiB、累计 8 MiB、整体 8 秒，旧浏览器无流接口时跳过预加载。
资源不可用会回退为占位或可结束的错误状态，不阻塞整个课程。

网页活动的 opaque sandbox 与完成消息协议见
`packages/activities/src/SECURITY.md`。
