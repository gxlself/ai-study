# 播放端开发夹具

本目录全部文字与图片均为 **开发夹具，非生产内容**，只验证播放端的数据契约与离线流程，不是经过审定的课程、发育评估或屏幕时长建议。课程与 SVG 在本任务中编写，未使用第三方图片、录音、研究引文或外部来源，不虚构来源和授权。

`sprout.core/bundle.json` 是独立 `PackBundle`，包含六个词条、四节单步骤课程和一条六阶段路线（6–8、9–11、12–17、18–23、24–29、30–36 月）。每个阶段只引用覆盖该阶段月龄的课程，没有阶段横跨 23/24 月边界。

- 保留 `core.fixture.word-cards`、`core.fixture.count`、`core.fixture.choose`，均为 `audience: "child"`、18–36 月、`coView: "required"`，每课 1 分钟。
- 新增 `core.fixture.parent-guide`：`audience: "parent"`、6–36 月，家长阅读 1 分钟，`guide.playMin: 5` 为屏幕变暗后的离屏陪玩计时，不计入孩子屏幕预算。带苹果和球的大号可打印实体卡，以及完整目标、材料、双语示范用语、步骤、观察点与安全提示。
- 四课的线下活动都有 `question` 与 `levels.easier/harder`；原 `steps` 是中档玩法。家长看屏幕后去陪玩，不要求宝宝作答。

| 月龄 | childScreen | 默认计划 | 家长主动开启共看 |
|---|---|---|---|
| 6–17 | none | 1 节家长课 | 无效，仍只提供家长课 |
| 18–23 | optional | 1 节家长课 | 1 节家长课 + 1 节词卡共看课 |
| 24–36 | default | 3 节共看课；首页另补家长指引区 | 同默认；也可切回仅家长课 |

短时屏幕策略仅供流程测试：18–23 月开启共看后单次、每日均为 1 分钟，计划两课包含家长课；24–36 月主题三张共看卡，单次 2 分钟、每日 3 分钟，家长课由首页补充。孩子预算只累计共看课。6–17 月策略中的 1 分钟数值不代表允许宝宝看屏幕。

孩子可见标题、提示保留简短内容名称，不反复插入开发声明；包名、包说明、署名、词条标签和 SVG 描述标识开发用途，家长导语以“这是开发演示。”开头。没有音频文件，`audio/manifest.json` 的 `voices` 和 `entries` 都为空，供宿主验证 Web Speech / 静默回退。

家长课覆盖 6–36 月以验证所有阶段的家长入口，`validateLesson` 会产生一条月龄跨度大于 18 个月的已知警告，校验脚本只允许这一条；三节共看课不再有跨度警告。所有课程结构、词条与打印引用、资源、分龄策略和阶段覆盖仍严格校验。

`playMin: 5` 特意长于 3 分钟无输入阈值，供宿主验收变暗陪玩阶段的暂停豁免；夹具校验本身不代表运行时豁免、会话记账或打印渲染已通过。宝宝始终由家长陪同，不是无人看护。

仓库中有正式 `content/packs/sprout-core/bundle.json` 时，复制脚本不会使用本目录。正式包存在但损坏时直接报错，不静默切换为夹具。

在仓库根验证：

```sh
node apps/player/scripts/validate-fixtures.mjs
```
